# 豹语（DiceScript）编写指导

豹语是海豹内置的骰点脚本语言（独立于 JS 的 goja 环境），用于自定义文案、自定义回复、
牌堆与指令输出中的文本模板。实现仓库：sealdice/dicescript（Go/JS 双版本），
完整教程见其 `docs/GUIDE.md`；在线试玩 https://sealdice.github.io/dicescript/ 。

## 1. 海豹变量（手册 script.md 验证）

| 前缀 | 作用域 | 示例 |
|---|---|---|
| `$t` | 个人临时变量，仅单次指令执行有效 | `$t随机点数` |
| `$m` | 个人持久变量（跨群） | `$m今日人品` |
| `$g` | 群变量（群内共享） | `$g群主体重` |

内置 `$t` 变量（每次指令开始时注入）：`$t玩家`（带<>）、`$t玩家_RAW`、`$tQQ昵称`、
`$t账号ID`、`$tQQ`、`$t群名`、`$t群号`、`$t群组骰子面数`、`$t个人骰子面数`、
`$t骰子账号`、`$t骰子昵称`、`$tDate`（如 20260109）、`$tYear`、`$tMonth` 等。

## 2. 语法要点（dicescript GUIDE 验证）

- 变量无需声明；语句块不隔离变量；函数内有独立变量空间。
- 类型：int / float / string / array / dict / computed（计算值）/ function / null。
- 算符：`+ - * / %`、比较 `> >= == != < <=`、逻辑 `& | && ||`、三元 `?:`、空值合并 `??`。
- 流程控制：`if ... else ...`、`while`；支持 `return`。
- 数组：`[1,2,3]`、`[1..5]`（1..5）、`[5..1]`（反向）；方法 `len/pop/push/shift`。
- 字典：`{k:v}`，键必须是字符串（数字自动转字符串）；方法 `len/get`。
- 内置函数：`floor/ceil/round/abs`、`int/float/str/bool`、`repr`、
  `load(name)`、`loadRaw(name)`、`loadRawAttr(obj,name)`、`loadRawItem(obj,key)`、
  `dir(obj)`、`typeId(obj)`。
- 骰点：`d20`、`3d20`、`2d20k1/kh`（取高）、`2d20q1/kl`（取低）、`dl/dh`（排除）、
  `min/max` 界定、`d20优势/劣势`、`f`（命运骰）、`b/p`（CoC 奖励/惩罚骰）、
  `XcYmZ`（双十字）、`a`（WoD 无限）。
- 模板插值：`{变量}` 输出变量值；`{% ... %}` 是执行块（海豹文案/回复中的写法）。

## 3. 在各场景中的用法

### 自定义文案（rollvm 模板）
- 插值：`{$t玩家} 的检定结果为 {$t结果文本}`。
- 嵌套调用其他文案：`{核心:骰子名字}`；`{$t判定结果}` 调用另一条文案。
- 图片/CQ 码：`[图:data/images/x.png]`。
- 引用牌堆：`#{DRAW-牌组名}`。

### 自定义回复
- 回复文本支持 `{变量}`、`{d100}` 掷骰、`{% %}` 执行块。
- 执行块示例：
  ```text
  {% $tRand = d6;
  if $tRand > 3 { $t输出 = `大` } else { $t输出 = `小` } %}
  {$t输出}
  ```
- 正则捕获组存入 `$t1`、`$t2`…，完整匹配 `$t0`，命名组 `(?P<A>cc)` 存 `$tA`。
- 限定每人每天：`if $m标记 != $tDate { ...; $m标记 = $tDate }`。
- 注意：豹语没有 `else if`，`if`/`else` 一对一配对；`||`/`&&` 从左到右，需括号。

### 牌堆
- 与文案不同，牌堆条目里用 `[...]` 包裹表达式：`你抽到了[$m金币=$m金币+114] 金币`。
- 嵌套抽取：`{key}`（不放回）/ `{%key}`（放回，TOML/JSON）；YAML 语义相反。
- 权重：条目最前 `::9::`。

### JS 插件
- 用 `seal.format(ctx, text)` 对模板字符串执行豹语/rollvm；`seal.formatTmpl(ctx, 'COC:检定_失败')`
  调用自定义文案。
- 玩家变量：`seal.vars.intGet(ctx, '$m金币')` / `strSet` 等，与 `$t/$m/$g` 互通。

## 4. 常见错误

- 全角符号（`，` `”`）导致解析失败——只允许半角。
- `$t` 变量不能跨指令使用（未定义行为），持久数据用 `$m`/`$g`。
- 未赋值变量默认值为 0。
- 文案递归嵌套会导致严重问题，禁止。
